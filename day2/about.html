About QuickNotes

Welcome to QuickNotes! This is a simple note-taking app. QuickNotes allows you to create, edit, and delete notes easily.

How to use QuickNotes

  1. Create new notes by clicking the "New Note" button.
  2. Edit existing notes by clicking on them.
  3. Delete notes by clicking the trash icon.

Features

  • Create new notes
  • Edit existing notes
  • Delete notes easily
  • Organize important information

Keyboard shortcuts

Shortcut Action
Ctrl + N Create a new note
Ctrl + S Save the current note
