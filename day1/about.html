About QuickNotes

Welcome to QuickNotes! This is a simple note-taking app.
QuickNotes allows you to create, edit, and delete notes easily.

How to use QuickNotes

Here are some tips to get the most out of QuickNotes:

  • Create new notes by clicking the "New Note" button.
  • Edit existing notes by clicking on them.
  • Delete notes by clicking the trash icon.
Feature Description
New Note Create a new note by clicking the "New Note" button.
Edit Note Edit existing notes by clicking on them.
